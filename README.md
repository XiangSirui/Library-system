# 科育邻里 · 微信小程序

MiniProgram 分支包含社区花园、图书借阅、活动室预约、书评和管理员功能。小程序采用原生 WXML / WXSS / JavaScript，后端采用 Flask / SQLite。手机与电脑微信布局使用自适应网格。

当前已完成微信登录、记录归属权限、预约门锁密码、生产部署文件与备份恢复工具。尚未部署到真实服务器，也未完成真实微信登录及手机真机验收。

## 账户与权限

- 花园、馆藏、公开书评、开放日历无需登录。
- 使用 wx.login 获取临时 code，服务端通过微信 code2Session 换取身份，建立内部账户。客户端不能提交 OpenID 来决定身份。
- 登录凭证为随机值，数据库仅保存摘要，有效期 7 天；客户端仅在本次运行内存中保留。退出和到期后失效。
- 个人借阅、预约、书评及照片按内部账户查询和校验。客户端传入其他手机号、ownerId 或记录编号无法获得其他账户权限。
- 手机号查询保留为当前微信账户已绑定记录内的筛选，不作为身份凭证。旧记录不会按手机号自动归并，由管理员到馆核验后逐条绑定，并保留审计记录。
- 管理员使用密码和 8 小时可撤销会话，写接口校验 CSRF。修改密码会撤销原管理员会话。
- 志愿照片仅允许本人或管理员鉴权查看，不通过静态资源兜底公开。小程序下载到临时文件后预览，退出时清理。
- 原网页保留公开浏览和管理员后台；个人操作引导到小程序。旧匿名查询和操作接口已关闭。

借阅规则仍为 30 天、同时最多 3 本、续借一次；活动室可预约今天起未来 14 天、连续 1–3 小时、最多 30 人。限制按微信账户计算。书评继续审核后公开。

## 活动室门锁密码

管理员在小程序“管理 → 预约”或电脑网页管理后台的预约记录中打开“门锁密码”，填写实体门锁已设置的密码。每条预约分别登记，支持替换和移除。

居民在“我的 → 活动室预约 → 查看门锁密码”主动查看：管理员保存后立即可见，到预约结束时自动隐藏；取消或提前签退也不可再读取。其他账户及未登录用户无法读取。密码不进入预约列表、公开日历、网址或本机存储，在服务端使用独立 DOOR_CODE_KEY 加密保存。

此功能不连接智能门锁。隐藏记录不能撤销居民已经记住的密码；管理员应在实体门锁上安排密码有效期或及时更换，并与预约中登记的密码保持一致。

## 本机开发

安装依赖并启动：
```powershell
& "D:\miniconda3\python.exe" -m pip install -r requirements.txt
& "D:\miniconda3\python.exe" scripts/dev_miniprogram.py
```

其他电脑使用已安装的 python 即可。脚本启动 127.0.0.1:5000，准备被 Git 忽略的 project.private.config.json 本机 HTTP 设置。保持服务运行，再在微信开发者工具导入仓库根目录并编译；无需构建 npm。后端未运行时，照片和日历无法加载。

真实微信登录还需要服务端凭据：
1. 尚无 server.local.json 时，将 server.local.example.json 复制为 server.local.json；已有文件直接编辑，保留原 DOOR_CODE_KEY。
2. 在本机编辑器中填入与 project.config.json 一致的 AppID 及 AppSecret；不要把 AppSecret 发到聊天或写进 miniprogram。
3. 门锁密码还需配置 DOOR_CODE_KEY（Fernet 密钥）；生成和保管方法见部署手册。
4. 停止旧后端并重新运行启动脚本。它会读取这个被 Git 和 Docker 忽略的文件；已有环境变量优先。
5. 使用真实小程序账号在开发者工具里登录验证。没有配置时服务会明确返回“微信登录尚未配置”，不会提供绕过认证的开发账号。

本机可做公开资源诊断：
```powershell
& "D:\miniconda3\python.exe" scripts/dev_miniprogram.py --check
```
会检查 15 天日历和 18 张花园照片，不修改业务记录。

手机上的 127.0.0.1 指向手机自身。手机预览必须改用可访问的 HTTPS 测试服务，不能沿用电脑回环地址。trial / release 域名默认留空，未配置时不回退本机地址。

## 生产部署、迁移和备份

完整步骤见 [部署手册](deploy/README.md)。包含：
- Docker Compose、Gunicorn、Caddy 自动 HTTPS；
- 数据库、照片及备份的持久化卷；
- 生产密钥检查、默认管理员密码拦截；
- SQLite 与照片一致备份、文件校验、安全恢复到新目录；
- 每日备份 systemd 定时任务及异地转存说明；
- 旧数据迁移与管理员核验绑定。

真实服务器、域名和 AppSecret 由运营方准备。备份脚本与恢复逻辑已用独立测试数据演练；外部部署、HTTPS 证书、异地存储和定时任务安装仍待实际环境验证。Docker 容器尚未在本机构建，不能将文件准备完成理解为已部署成功。
