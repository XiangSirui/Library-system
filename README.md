# 阅享空间 · 微信小程序

`MiniProgram` 分支为原社区花园与图书借阅项目增加原生微信小程序客户端。使用 WXML / WXSS / JavaScript；无需 WebView、第三方 UI 框架或云开发。现有 Flask API、SQLite 数据、网页入口及管理后台继续可用。

小程序源码已完成。**AppID 和体验版 / 正式版 HTTPS 域名尚未填写，尚未上传或发布。** 保留原项目的手机号查询方式；发布前请阅读本文的访问控制说明。

## 功能

| 页面 | 已迁移功能 |
| --- | --- |
| 花园 | 概览、平面导览、四季照片、共建故事、植物生命、原生图片放大 |
| 借书 | 分类与搜索、库存、图书详情、预约借阅与取书码 |
| 图书 / 读后感 | 已审核书评、评分、借阅资格检查、发布、编辑、删除和审核状态 |
| 活动室 | 今天起未来 14 天、开放 / 占用 / 过去时段、连续 1–3 小时预约、30 人容量限制 |
| 我的 | 按手机号查询借阅 / 预约及历史、续借、归还、取消、清除本机联系信息 |
| 签退 | 选择或拍摄志愿服务照片、格式与大小校验、说明、原生文件上传 |
| 管理 | 管理员登录、统计、图书增改删、归还确认、书评审核、预约取消、材料查看、逐日或整个日期范围开放设置 |

借阅规则保持 30 天、同时最多 3 本、可续借一次；活动室每天每人一次，提前至少 1 小时取消，开始后提交材料签退。后端补齐了异常输入、日期范围、库存 / 时段并发和图片内容校验。未填写手机号时不会返回全部个人记录。

## 在微信开发者工具中运行

1. 安装 Python 依赖并启动后端：

   ```powershell
   python -m pip install -r requirements.txt
   python app.py
   ```

   当前电脑可使用 `D:\miniconda3\python.exe`。后端默认监听 5000 端口；旧网页是 `http://127.0.0.1:5000/`，花园是 `/garden`，管理入口是 `/admin/login`。

2. 微信开发者工具选择「导入项目」，**目录选择仓库根目录**（有 `project.config.json` 的目录）。配置中的 `miniprogramRoot` 已指向 `miniprogram/`，无需「构建 npm」。根目录 npm 依赖仅供开发检查，不进入小程序代码包。

3. 当前 `appid` 是 `touristappid`，用于本机无 AppID 的开发；取得实际 AppID 后，替换 `project.config.json` 的 `appid`。游客模式的能力以开发者工具实际支持为准，不能用于正式上传。

4. `miniprogram/config.js` 的 `develop` 默认是 `http://127.0.0.1:5000`。本机模拟器联调 HTTP 时，可在开发者工具本地设置中关闭合法域名校验。此设置只用于本机调试，项目默认仍开启域名校验。

5. 手机真机上的 `127.0.0.1` 指向手机自身。真机测试请将 `develop` 改成可访问的测试 HTTPS 域名，并配置对应服务器域名。不要把 AppSecret 或管理员密码写入小程序。

域名配置示例：

```javascript
const environments = {
  develop: 'https://测试域名',
  trial: 'https://正式服务域名',
  release: 'https://正式服务域名'
};
```

未配置体验 / 正式域名时客户端会明确提示服务未配置，不会自动回退到 localhost。照片由后端静态资源地址提供，未复制进代码包；书籍使用本地排版封面，不依赖外部图书封面服务。

## 手机与电脑适配

- 原生底部四个导航入口，输入框、日期 / 时长选择器、图片预览与文件上传。
- 开启 `resizable`，适配电脑微信窗口调整。
- 700 px 以下采用单列业务表单、双列馆藏；700 px 起采用双列内容 / 表单与三列馆藏；1100 px 起四列馆藏。
- 页面宽度限制为 1200 px；正文和控件使用 px，避免电脑大窗口下 rpx 等比例放大。包含底部安全区内边距。
- 页面含加载、重试、空数据、重复提交保护；查询手机号变化时立即清空旧记录并忽略旧请求的迟到响应。

**视觉复查范围：** 已用独立无头 Edge 渲染官方编译的 WXML/WXSS，检查 22 种页面状态 × 7 个宽度（320、375、414、700、768、1024、1440 px），并查看截图；修复了长英文标题溢出、卡片裁切、按钮默认宽度干扰、小字对比度与材料弹窗关闭入口。154 个布局组合均通过检查，报告和截图在 `.qa/layout/`。预览脚本使用模拟原生组件，未连接个人浏览器或读取真实借阅数据。

**尚需微信原生环境验收：** 上述浏览器检查不能代替微信开发者工具与真机，原生选择器、键盘、安全区、权限弹窗及字体差异仍待验证。此前针对个人浏览器的界面预览被自动安全检查中止；后续布局复查使用独立测试浏览器完成。

建议在 320 / 375 / 414 px 手机、768 px 平板、1024 / 1440 px 电脑窗口逐页检查，重点验收：软键盘与表单滚动、底部安全区、长书名、窗口缩放、照片选择权限 / 拒绝 / 取消、电脑相册选择、管理员会话与材料预览。

## 服务端与发布配置

小程序上传的是客户端，Flask 后端需单独部署到能通过 HTTPS 访问的服务器。现有 `render.yaml` 仍是原部署配置，并补充 `TZ=Asia/Shanghai`。

| 环境变量 | 用途 |
| --- | --- |
| `SECRET_KEY` | 生产环境随机会话密钥，所有进程使用同一个值 |
| `FLASK_DEBUG=0` | 关闭开发调试 |
| `TZ=Asia/Shanghai` | Linux 服务业务时间，与小程序的北京时间一致 |
| `LIBRARY_DB_PATH` | SQLite 持久化文件的绝对路径，父目录需存在 |
| `LIBRARY_UPLOAD_DIR` | 志愿照片持久化目录；返回 URL 仍是 `/static/uploads/volunteer/...` |
| `PORT` | 服务监听端口，默认 5000 |

生产环境使用 Gunicorn / HTTPS 反向代理，例如：

```sh
gunicorn app:app --bind 0.0.0.0:5000
```

SQLite 和照片必须挂载到持久化磁盘并备份。原 Render 免费配置的临时文件系统不能作为正式借阅数据存储；应选择支持持久化磁盘的部署环境。保持单个共享数据库文件，不要把多个实例的独立磁盘当成同一个数据库。

初始管理员沿用原系统账号。已有数据库不会被重建或重置密码。首次初始化后、对外开放前，在服务器交互式终端设置自己的管理员密码：

```sh
python scripts/set_admin_password.py --username admin
```

脚本两次隐藏输入密码，只更新指定管理员，不能用于未初始化的数据库，不会修改借阅记录。无需把密码放到命令行或文档中。

取得 AppID 与域名后：

1. 在小程序后台配置实际 HTTPS 域名的 request、uploadFile、downloadFile 服务域名；在 `config.js` 填好各环境。
2. 按实际运营主体填写微信的隐私保护指引、服务类目、联系方式及要求的信息；程序内的隐私说明不代替微信后台配置。
3. 使用真实账号验证借阅、书评审核、预约、签退以及管理员操作；同时测试网络断开、拒绝授权和未登录。
4. 在微信开发者工具中预览 / 真机调试，通过后上传体验版，再提交平台审核与发布。

官方参考：[项目配置](https://developers.weixin.qq.com/miniprogram/dev/devtools/projectconfig.html)、[网络能力](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[显示区域适配](https://developers.weixin.qq.com/miniprogram/dev/framework/view/resizable.html)。

### 当前访问控制边界

本分支按需求保持原项目“姓名 + 手机号”的业务方式，**手机号是记录查询条件，不是身份认证**。未引入 `wx.login`、OpenID 绑定或短信验证，且为兼容旧网页保留部分不传手机号的旧操作接口。因此，当前适合延续原系统的小范围受控使用；面向公众开放前，应将个人记录查询、借还 / 预约 / 签退绑定到经过验证的用户身份并收紧旧接口。只隐藏前端按钮不能替代服务端鉴权。

管理员仍使用既有密码登录和 Flask session；小程序显式管理 Cookie，仅发送到管理员接口。会话仅保存在运行内存中，退出或 401 时清除。AppSecret 不需要进入当前代码。

## 检查与维护

```sh
npm ci
npm run check
npm test
npm run compile
npm run test:layout
python -m unittest discover -s tests -p "test_*.py" -v
```

- `check`：页面文件、JS / JSON、模块依赖、WXML 事件、路由、资源与代码包体积检查。
- `test`：18 项 Node 行为回归，覆盖网络、Cookie、上传错误、借阅、书评、时段及跨手机号异步隔离。
- `compile`：微信官方 `miniprogram-compiler` 的 WXML / WXSS 编译，并执行全部页面初始渲染。该离线编译检查不代替最新微信基础库与真机验证。
- `test:layout`：将真实 WXML 编译树与 WXSS 渲染为独立测试页面，检查页面横向溢出、文字裁切、按钮最小尺寸、图片加载、弹窗关闭按钮，并输出截图。Windows 默认使用已有 Edge；其他系统先执行 `npx playwright install chromium`，也可用 `LAYOUT_BROWSER_PATH` 指定测试浏览器。不会读取个人浏览器配置。
- Python：18 项 API 集成测试，使用独立临时数据库和照片目录；覆盖并发库存 / 预约冲突、数据校验、完整业务流程。
- 本次上述检查全部通过，现有 `library.db` 与志愿照片未作为测试数据使用。
- `scripts/generate_miniprogram_icons.py` 可重新生成底部导航图标。
